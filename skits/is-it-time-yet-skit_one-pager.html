Is It Time Yet?

Cub Scout skit · simple props · About 1 minute

A very important question travels down a line. The answer leads to a very small change.

Cast4-8 Scouts
PropsNone
LengthAbout 1 minute
Best forLions and Tigers

Setup

  • Scouts stand in a row facing the audience, arms folded and ankles loosely crossed.
  • The first Scout starts each question; the last Scout gives the answer.

Script

First Scout
Is it time yet?
Stage note
Each Scout turns to the next and repeats "Is it time yet?" until the question reaches the end.
Last Scout
No.
Stage note
Each Scout passes "No" back along the row. Wait two seconds.
First Scout
Is it time yet?
Stage note
Pass the question down again, then pass the last Scout's "No" back. Wait two seconds.
First Scout
IS IT TIME YET?
Stage note
Pass the question down one final time.
Last Scout
Yes!
Stage note
Pass "Yes!" back. When it reaches the first Scout, that Scout nods. Everyone uncrosses their arms and ankles, then crosses them the other way. Hold the new pose for a beat, then exit.
Leader note

Rehearse the final movement first, using the first Scout's nod as the cue. Keep ankles loose and feet on the ground for balance. Use folded arms alone if preferred. Three rounds are enough; avoid long waits.
